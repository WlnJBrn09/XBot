# X0 verification

The daemon reserves the full `org.cruxos.XBot1.Daemon` method and signal names. Only `Status()` is active. This is deliberate: X0 does not monitor, send data to providers, change settings, or run a helper.

On Debian 13, run:

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo build --workspace
cargo test --workspace
sh tests/x0-status.sh /tmp/xbot-status.json /tmp/crux-help.json
cat /tmp/xbot-status.json
dpkg-buildpackage -us -uc -b
```

The status command must return a JSON object with `"schema":"xbot.status/1"`.

With the daemon running, `cargo run -p xbot-chat` opens the XBot window. It must show "XBot 0.1.0 · X0" at the bottom of the sidebar; problem detection and chat read as not available yet. The `xbot-chat` tests check the design tokens and WCAG 2.x contrast, the API routes and error mapping, the settings round trip, and that every referenced asset and icon exists. The CI workflow runs the Rust checks and package build in a Debian 13 container. A real graphical session service start and installed package test still require a Debian 13 VM.
